# Protocol release contents

- `analysis-config-v1.json`: machine-readable thresholds, datasets, seeds, and weights.
- `validation-endpoints-v1.tsv`: immutable temporal endpoints and biological units.
- `known-targets-v1.txt`: known later targets, recorded openly rather than presented as blinded.

The narrative protocol is in `../preregistration.md`; exact score construction is in
`../model-specification.md`. Their release hashes are recorded together before expression access.
